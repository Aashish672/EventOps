# Implement Feature

1. Read docs/PRD.md and the relevant architecture and data-model documents.
2. Restate the feature requirements and acceptance criteria.
3. Identify affected backend, frontend, database, tests and documentation.
4. Identify security, tenant-isolation, concurrency and failure-handling risks.
5. Propose a short implementation plan. Do not edit files until the plan is approved.
6. Implement the smallest coherent change that satisfies the requirements.
7. Add or update meaningful tests, including negative and permission tests where relevant.
8. Run the relevant tests, linters and type checks.
9. Inspect the final diff for unrelated changes, secrets and unsafe assumptions.
10. Summarize files changed, design decisions, commands run, test results and remaining risks.
11. Do not commit, push or deploy unless explicitly requested.
12. Always work on a feature branch
